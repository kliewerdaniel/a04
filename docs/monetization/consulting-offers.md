# Consulting Service Packages

## Philosophy

Fixed-price, scope-defined engagements. No hourly billing, no scope creep, no surprises. Each package has clear deliverables, timelines, and success criteria.

## Package Matrix

### AI Systems Audit
- **Price:** $500
- **Duration:** 1 week
- **Delivery:** Remote
- **Deliverables:**
  - Current state assessment (systems, data, workflows)
  - Opportunity map (highest-impact AI applications)
  - Architecture recommendations (3 options with trade-offs)
  - Implementation roadmap with timeline and budget estimates
  - 30-minute findings presentation (recorded)
- **Process:**
  1. Kickoff call (30 min)
  2. Systems review (async)
  3. Interviews with key stakeholders (2-3 calls)
  4. Analysis and documentation
  5. Findings presentation (30 min)
- **Who it's for:** Organizations unsure if AI applies to them

### Technical Sprint
- **Price:** $5,000–$10,000 (depending on complexity)
- **Duration:** 2 weeks
- **Delivery:** Remote with daily async updates
- **Deliverables:**
  - Working prototype or production-ready feature
  - Architecture documentation
  - Deployment guide
  - Source code (your IP)
  - Knowledge transfer session (1 hour)
- **Process:**
  1. Week 1: Setup, data integration, core architecture
  2. Week 2: Feature completion, testing, deployment
  3. End: Demo + handoff
- **Who it's for:** Teams with a clear use case but no AI expertise

### Full System Build
- **Price:** $10,000–$25,000
- **Duration:** 4–8 weeks
- **Delivery:** Remote with weekly demos
- **Deliverables:**
  - Production-ready AI system
  - Complete architecture documentation
  - Monitoring and alerting setup
  - Team training session (2 hours)
  - 30-day post-deployment support
  - Maintenance guide
- **Process:**
  1. Week 1: Architecture finalization + environment setup
  2. Weeks 2-3: Core system development
  3. Week 4: Testing, optimization, deployment
  4. Week 5+: Buffer for feedback, training, documentation
- **Who it's for:** Organizations needing a complete AI system

### Fractional AI Engineer
- **Price:** $5,000/month
- **Commitment:** 3-month minimum
- **Hours:** ~20 hours/week (flexible)
- **Includes:**
  - Architecture guidance
  - Code reviews
  - Sprint planning participation
  - Direct Slack/email access
  - Monthly strategy session
  - Emergency support (within business hours)
- **Who it's for:** Teams that need ongoing AI expertise without full-time hire

## What's Included in All Packages

- NDA-friendly (standard mutual NDA)
- Git-based version control
- Weekly progress reports
- Documentation
- 30-day email support after completion

## What's NOT Included

- Long-term maintenance (separate retainer)
- Cloud infrastructure costs
- Third-party API costs
- Training team members on basics (unless scoped)
- Ongoing content/data updates
