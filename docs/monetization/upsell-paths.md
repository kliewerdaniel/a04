# Upsell & Expansion Paths

## The Client Journey

```
Free Content → Lead Magnet → Audit ($500) → Sprint ($5-10k) → Full Build ($10-25k) → Retainer ($5k/mo)
     │             │              │              │                  │                   │
     ▼             ▼              ▼              ▼                  ▼                   ▼
  Awareness     Interest      Evaluation     First Buy          Expansion          Ongoing
```

## Expansion Opportunities

### Post-Audit Upsell
- **Trigger:** Client receives audit findings
- **Offer:** Technical Sprint to implement top recommendation
- **Discount:** 10% off sprint if booked within 14 days of audit

### Post-Sprint Upsell
- **Trigger:** Sprint delivers working prototype
- **Offer:** Full System Build to productionize
- **Discount:** 15% off Full Build if booked within 30 days
- **Add-on:** Training session for their team ($1k)

### Post-Full Build Upsell
- **Trigger:** System deployed and stable
- **Offer:** Fractional AI Engineer retainer ($5k/mo)
- **Value:** Ongoing optimization, feature additions, monitoring

### Cross-Sell Paths

| Initial Service | Cross-Sell | Timing |
|---|---|---|
| Knowledge System | Automation Pipeline | After knowledge system is live |
| Local AI Deployment | Monitoring + Maintenance | 30 days post-deployment |
| Technical Sprint | Team Training | During handoff |
| Audit | Full System Build (skip sprint) | During audit findings |
| Digital Product Purchase | Consulting (level up) | After product purchase (qualify call) |

## Client Referral Program

- **Offer:** 1 month retainer free (or $5k credit) for referring a client who signs a Full Build
- **Structure:** Referrer gets 10% of first engagement value
- **Process:** Unique referral link or discount code

## Email Upsell Sequence

### Post-Audit Sequence
1. Day 1: Deliver audit report
2. Day 3: "Here's what the next step looks like" → Sprint proposal
3. Day 7: Case study similar to their findings
4. Day 14: "Last chance for 10% discount" → Sprint booking

### Post-Product Purchase Sequence
1. Day 1: Delivery + setup guide
2. Day 3: "Need help customizing this?" → Consultation offer
3. Day 7: Case study showing product in production
4. Day 14: Free discovery call offer

## Cancellation/Churn Prevention

- Before retainer cancellation: "What's not working?" → Adjust scope
- If pricing objection: Downgrade hours, not cancel
- If solved: Case study permission + referral ask
- 30-day cooling period before full cancellation
