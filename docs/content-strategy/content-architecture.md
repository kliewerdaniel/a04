# Content Architecture

## Content Model

The site has four content types, each with distinct goals and audiences:

| Type | Primary Goal | Volume | Update Frequency |
|---|---|---|---|
| Blog posts | SEO traffic, authority, lead gen | 120+ existing, 4-8/month new | Weekly |
| Case studies | Proof, conversion | 3-10 total | As projects complete |
| Resources/Lead magnets | Email capture | 5-15 total | Monthly |
| Lab experiments | Authority, differentiation | 3-5 active | Ongoing |

## Content Categories & Distribution

| Category | % of Content | SEO Volume | Conversion Rate | Effort |
|---|---|---|---|---|
| Technical Guides | 40% | High | Medium | High |
| AI Philosophy | 15% | Low | Low | Medium |
| Tutorials | 20% | Medium | Medium | Medium |
| Project Write-ups | 15% | Medium | High | High |
| News & Opinion | 10% | Medium | Low | Low |

**Optimal mix for business goals:**
- 50% Technical Guides (traffic + authority)
- 20% Project Write-ups disguised as case studies (conversion)
- 15% Tutorials (traffic + lead gen)
- 10% AI Philosophy (differentiation)
- 5% News & Opinion (timely, topical)

## Content Sourcing

| Source | Type | Frequency |
|---|---|---|
| Client projects (anonymized) | Case studies + Technical guides | Monthly |
| Open-source experiments | Project write-ups | Bi-weekly |
| Industry trends + personal takes | News & Opinion | Weekly |
| Deep dives on specific technologies | Technical guides | Weekly |
| Recurring series (e.g., "Local LLM of the Week") | Tutorials | Weekly |

## Editorial Standards

| Standard | Requirement |
|---|---|
| Minimum length | 800 words (philosophical), 1500 words (technical) |
| Code examples | Every technical post must have working code |
| SEO metadata | Title, description, tags, OG image required |
| Internal links | Min 2 links to other site content |
| External references | Min 1 link to source/paper/tool |
| Reading time | Calculate and display |
| Proofreading | Grammar check, technical accuracy review |
| Publication day | Tuesday or Thursday AM (consistent) |

## Content Formats

### Standard Blog Post
Title → Description → Category + Tags → Introduction → Body (H2/H3) → Code blocks → Images → Conclusion → CTA → Author bio → Related posts

### Tutorial
Title → Prerequisites → Step 1 → Step 2 → ... → Step N → Complete code → Testing → Troubleshooting → Next steps

### Case Study
Title → Client context → Problem → Approach → Architecture diagram → Implementation → Code snippets → Results (metrics) → Lessons learned → CTA

### Philosophical Essay
Title → Hook → Thesis → Exploration → Counter-arguments → Synthesis → Questions for the reader → CTA (newsletter)
