# About Page Specification

## Purpose

Build trust through personal narrative. Explain who Daniel Kliewer is, why local AI matters, and how this philosophy translates into client value. The about page is a conversion page — it should make visitors want to work with this person.

## Target Audience

- Prospective clients evaluating the person behind the consultancy
- Community members interested in the personal story
- Media/podcast hosts researching guests

## Conversion Goals

| Goal | Metric |
|---|---|
| Book consultation | CTA click |
| Subscribe to newsletter | Email signup |
| Download resume/credential | PDF download |

## Tone

- Personal but not overly emotional
- Intellectually confident but humble
- Clear about values without being preachy
- "This is what I believe, here's why, here's what I've built"

## Key Principles

1. **Show, don't tell** — Instead of "I'm an expert in AI systems," say "I've built knowledge graph systems that process 50k documents, RAG pipelines with dynamic persona routing, and multi-agent automation architectures."
2. **Philosophy with proof** — Every belief should be backed by a project or post
3. **Human + technical** — Let personality show through while maintaining technical credibility

## CTA Strategy

| Book a Free Consultation | Final CTA | /contact |
| Read the Blog | Final CTA (secondary) | /blog |
| View GitHub | Public Presence section | GitHub profile |
| Download Resume | Expertise section | PDF download |

## SEO Targets

- **Primary:** "Daniel Kliewer AI consultant", "Austin AI engineer"
- **Secondary:** "AI systems engineer bio", "local AI consultant"
- **Title:** "About — Daniel Kliewer, AI Systems Engineer"
- **Description:** "Austin-based AI systems engineer building local-first AI infrastructure. 120+ technical articles on AI systems, local LLMs, and production automation."

## Mobile Behavior

- Profile photo smaller but still prominent
- Timeline becomes vertical list instead of horizontal
- Expertise tags wrap naturally
- CTAs full-width
- Philosophy section collapses to shorter text
