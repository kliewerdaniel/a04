# SEO Strategy & Marketing

## SEO Foundation

The SEO strategy is built on three pillars:

1. **Technical SEO** — Proper metadata, schema, sitemaps, performance
2. **Content SEO** — Deep, original technical content targeting specific queries
3. **Authority SEO** — Backlinks from established tech publications, GitHub stars, community presence

## Keyword Strategy Focus

### Primary Keywords (High Volume, High Competition)
- "AI consulting" — Target via pillar pages and authority
- "AI systems engineer" — Target via about page and personal brand
- "local LLM" — Target via technical guides (existing strength)

### Secondary Keywords (Medium Volume, Medium Competition)
- "RAG implementation", "knowledge graph AI", "AI agent development"
- "private AI deployment", "on-premise LLM"
- "AI workflow automation", "AI content pipeline"

### Long-Tail Keywords (Lower Volume, Low Competition)
- "How to build RAG with Ollama and LangChain"
- "Local LLM deployment for enterprise compliance"
- "AI agent architecture for customer support automation"
- "Private knowledge base with local embeddings"

## Content SEO Rules

| Rule | Implementation |
|---|---|
| One primary keyword per post | Use in H1, first paragraph, meta title |
| 2-3 secondary keywords | Use in H2s, body text naturally |
| Internal links | Min 2 links to other site content |
| External links | Min 1 high-authority reference |
| Meta description | Include keyword + value prop + CTA |
| URL slug | Include primary keyword, no stop words |
| Image alt text | Descriptive, include keyword where natural |
| Reading time | Display prominently |
| Schema markup | TechArticle or Article type |

## Off-Page SEO

| Tactic | Priority | Expected Impact |
|---|---|---|
| GitHub open-source repos | High | Direct backlinks + developer audience |
| Hacker News posts | Medium | High-value backlinks when successful |
| Guest posting on AI publications | Medium | Authority backlinks |
| Twitter/X technical threads | Medium | Social signals, direct traffic |
| LinkedIn publishing | Low | Professional audience, modest traffic |
| Podcast appearances | Low | Niche backlinks, personal brand |
| Reddit (r/LocalLLaMA, r/MachineLearning) | Tactical | Targeted traffic, community credibility |

## Local SEO

- Google Business Profile (if offering local services in Austin, TX)
- Location-specific pages or mentions ("Austin AI consultant")
- Consistent NAP (Name, Address, Phone) across directories
